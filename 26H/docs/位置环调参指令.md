# 球位置环（最外环）串口调参指令

> 工程：`26h`
> 调试口：**USART1**，115200 8N1
> 命令格式：字母 + 数值，**回车**结尾，大小写都认
> 前置：角度环已能 `T0` 静置（见 `docs/角度环调参指令.md`）

---

## 1. 三环结构

```text
视觉mm → 位置环 10ms（100Hz）→ 目标倾角° → 角度环 5ms → 目标RPM
                                → 速度环 2ms → 电压 → CAN
```

| 环 | 周期 | 定时器 | 输入 → 输出 | 增益命令 |
|----|------|--------|-------------|----------|
| 位置环（最外） | **10ms（100Hz）** | TIM7 分频2 | 球位置 mm → 倾角 ° | **X / Y / Z** |
| 角度环（中） | 5ms | TIM7 | raw tick → RPM | J / K / L |
| 速度环（内） | 2ms | TIM6 | RPM → 电压 | P / I / D |

位置环输出直接写 `mubiao_qingjiao`，所以**工作半宽 ±14° 和软限位 5802~7457 全程照旧生效**，位置环没法绕过它们。

## 2. 上手顺序（第一次跑球，务必按这个来）

### 2.1 先确认视觉在说话

```text
A1
```

看 `vis=` 有数、`conn=1`、`vrx` 在涨。球放中间时 `vis` 应该接近 0。
`conn=0` 就别往下走了，先查 USART2。

### 2.2 标定推球方向（最重要的一步）

倾角往哪边推球取决于机械装法，代码里猜不出来。

```text
E1
T2          （手动歪一点点）
```

看球往哪边滚，和 `vis` 的正负对上：

- 球朝 `vis` **变大**的方向滚 → 后面用 **N-1**
- 球朝 `vis` **变小**的方向滚 → 后面用 **N1**

> 判断依据：位置环要让球往「误差减小」的方向走。
> 符号反了的表现很明显：**球一路加速跑到底，完全不回头**。
> 看到这个立刻 `S`，然后敲反的 N。

### 2.3 小步试跑

```text
T0          （先回水平）
H3          （倾角先只给 ±3°，稳了再放开）
M40         （变化率也先压住）
X0.03       （Kp 先给小的）
Z0.08
N1          （或 N-1，按 2.2 的结论）
B1          （开位置环）
```

球放偏一点松手，看它回不回中间。**不回或很肉 → 加 X；冲过头来回晃 → 加 Z。**

### 2.4 放开限幅

稳了之后逐步放：`H4` → `H5` → `H6`，`M60` → `M80`。

### 2.5 存档

```text
SAVE
```

## 3. 命令表

### 3.1 位置环增益

| 命令 | 参数 | 默认 | 单位 | 说明 |
|------|------|------|------|------|
| **X0.05** | 位置 Kp | **0.050** | °/mm | 50mm 偏差 → 2.5° |
| **Y0** | 位置 Ki | **0** | °/(mm·拍) | 先别加；改 Y 会清积分 |
| **Z0.08** | 位置 Kd | **0.080** | — | 刹车项，冲过头就加这个 |

> ⚠️ 默认值是按「±100mm 行程、±6° 倾角」估的**起点**，不是实测最优。
> 你的水管长度/球重/摩擦一变，量级就变了。以 2.3 的现象为准。

### 3.2 位置环开关与限幅

| 命令 | 含义 | 默认 |
|------|------|------|
| **B1** | 开位置环（自动进角度模式） | 开机 **1**（开） |
| **B0** | 关位置环，退回手动 T | |
| **G0** | 目标球位置 mm，0=水管中心 | **0** |
| **H6** | 输出倾角限幅 °（不超工作半宽） | **6.0** |
| **U0** | 位置死区 mm，0=关 | **0（关）** |
| **M60** | 倾角变化率限幅 °/s | **60** |
| **N1 / N-1** | 推球方向符号 | **1** |

**启动默认：** 位置环和电机均默认开启；但没有 CAN 反馈时速度环保持零输出。`E0` 或 `S` 停机后，仍可用 `E1` 手动恢复。
其余 8 个参数都存。

## 4. 模式互斥（别踩这个坑）

| 你敲的 | 位置环 | 结果 |
|--------|--------|------|
| **B1** | 开 | 位置环写倾角，`T` 失效（写了下一拍就被覆盖） |
| **B0** | 关 | 退回手动 `T`，角度模式保留 |
| **T±x** | **自动关** | 手动给倾角 = 明确要接管，会打印 `# qiu off (manual T)` |
| **V±x** | **自动关** | 纯速度模式，两个外环都让路 |
| **S** | **自动关** | 急停顺手关掉，否则 `E1` 一按球又跑 |

## 5. 丢球怎么办（已内置）

视觉超时 200ms 判丢球（`vision.connected=0`），位置环会：

1. 清积分和微分历史
2. **倾角按变化率限幅平滑回 0°（水平）**，不是保持原倾角
3. `qiu lost` 计数 +1（只在「刚断」那一拍加）

> 为什么不保持倾角：球看不见时继续歪着，球只会一路滚到底。

球回来时也不会踢一脚 D —— 首拍标志会把微分从 0 起算。

## 6. 看什么数（A0 数据行）

`A0` 默认每10ms输出一行位置环调参数据：

```text
qtgt:0.0,qpos:12.3,qerr:-12.3,qvel:0.45,qcmd:-0.62,qkp:0.050,qki:0.0000,qkd:0.080,qon:1,conn:1
```

| 字段 | 含义 |
|------|------|
| qtgt | 目标球位置 mm |
| qpos | 视觉原始球位置 mm |
| qerr | 位置误差 mm（目标 − 实测） |
| qvel | 球速 mm/拍（滤波后，正=正在往目标走） |
| qcmd | 位置环输出的目标倾角 ° |
| qkp / qki / qkd | 当前正在使用的位置环 PID 参数 |
| qon | 1=位置环在跑 |
| conn | 1=视觉在线 |

`Q` 命令会打两行 `# QIU`，含全部 8 个参数 + 丢球计数。

## 7. 现象 → 拧哪个旋钮

| 现象 | 优先动作 |
|------|----------|
| **球一路跑到底不回头** | **符号反了，`S` 然后敲反的 N** |
| 球回中心太慢/回不来 | 增大 **X**；确认 H 不是太小把输出憋住了 |
| 球冲过中心来回晃 | 增大 **Z**（刹车），或略减 X |
| 球在中心附近小幅颤 | 减 **Z**；还颤再开 **U**（死区 3~5mm） |
| 大偏差时倾角一脚踩到底、晃很久 | 收窄 **H**、压低 **M** |
| 倾角看着在动但球不动 | 倾角太小推不动，放宽 **H** 或加 **X** |
| qcmd 一直贴在 ±H | 输出饱和，加 X 没用了，放宽 H 或查机械 |
| 稳态总停在偏一点的位置 | 才考虑加 **Y**（很小，如 0.0005） |
| `qon=1` 但倾角不动 | 看 `conn`：视觉断了就是倾角回 0 |

## 8. 与角度环的分工（别在错的地方调）

| 抖/晃发生在 | 该调 |
|-------------|------|
| 倾角本身抖（`raw` 在 traw 附近晃） | 角度环 **L / J** |
| 倾角平稳但球来回滚 | 位置环 **Z / X** |
| 大步进倾角晃一阵 | **H / M** 限幅兜（今晚定的调子） |

角度环 `T0` 静置已经够稳，位置环就当它是个「给倾角就能到位」的执行器，别再回头抠它。
