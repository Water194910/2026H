# GM6020 角度环 / 速度环 串口调参指令

> 工程：`26h`  
> 调试口：**USART1**，115200 8N1  
> 命令格式：字母 + 数值，**回车**结尾，大小写都认  
> 默认在宏里；调完可 **W** 写入 Flash，上电自动加载

---

## 1. 控制结构（调参时心里有数）

```text
T(倾角°) → raw 目标 → 角度环 5ms → 目标 RPM → 速度环 2ms → 电压 → CAN
                ↑
         零点 raw=6493，工作 ±14°
```

| 环 | 周期 | 作用 | 串口增益命令 |
|----|------|------|----------------|
| 速度环（内） | TIM6 **2ms** | RPM → 电压 | **P / I / D** |
| 角度环（外） | TIM7 **5ms** | raw 误差 → 目标 RPM | **J / K / L** |

**先内后外、先 P 后 D。** 角度环抖优先动 **L（Kd）**，不是速度环的 D。

---

## 2. 模式与目标

| 命令 | 含义 | 说明 |
|------|------|------|
| **T0** | 角度模式：水平 | 相对水平 **0°** → raw 目标 **6493** |
| **T3** | 角度模式：+3° | `raw ≈ 6493 + 3×22.76` |
| **T-2** | 角度模式：-2° | 负数反方向 |
| **T14 / T-14** | 工作区边缘 | 再大也会被夹在 **±14°** |
| **V20** | **速度模式** | 直接目标 20 RPM；角度环让路 |
| **V0** | 速度目标清零 | 仍是速度模式 |

换算（内部自动做，人不用算 raw）：

```text
1° ≈ 8192/360 ≈ 22.76 tick
目标 raw = 6493 + T × 22.76
再夹紧：工作 ±14°，且不超过软限 5802~7457
```

| 模式 | 如何进入 | 谁写 `mubiao_sudu` |
|------|----------|-------------------|
| 角度 `mode=1` | 发任意 **T…** | 角度环 |
| 速度 `mode=0` | 发任意 **V…** | 串口直接给 RPM |

---

## 3. 使能 / 急停 / 打印

| 命令 | 含义 |
|------|------|
| **E1** | 使能电机（清两环积分） |
| **E0** | 停机（不出力） |
| **S** | 急停：停机 + 速度目标 0 + 清两环积分 |
| **A0** | PID 数据行（约 10ms，调参看曲线） |
| **A1** | 角度/视觉注释行（约 100ms） |
| **Q** | 查询当前参数与状态 |
| **W** 或 **SAVE** | 保存当前全部参数到 Flash（掉电保持） |
| **R** 或 **LOAD** | 从 Flash 重新加载（不重启） |
| **F1 / F-1** | 转向标定（正转速 raw 变大=1，变小=-1） |

---

## 4. 增益命令

### 4.1 角度环（外环，5ms）— 调抖主要动这里

| 命令 | 参数 | 默认 | 说明 |
|------|------|------|------|
| **J0.12** | 角度 Kp | **0.12** | RPM / tick |
| **K0** | 角度 Ki | **0** | 先不要加；改 K 会清角度积分 |
| **L0.10** | 角度 Kd | 出厂默认代码里是 **0.40**，实测静置更推荐 **0.10** | 抖优先降 L |

### 4.2 速度环（内环，2ms）— 已调过，尽量先别动

| 命令 | 参数 | 默认 | 说明 |
|------|------|------|------|
| **P55** | 速度 Kp | **55** | 联调默认 |
| **I0.55** | 速度 Ki | **0.55** | 改 I 会清速度积分；过大易来回晃 |
| **D0** | 速度 Kd | **0** | 联调默认 |

---

## 5. 限位与零点（只读常量，串口一般不改）

| 名称 | 值 | 含义 |
|------|-----|------|
| 硬限 raw | **5702 ~ 7557** | 机械极限附近断力兜底 |
| 软限 raw | **5802 ~ 7457** | 往外速度削 0，往里放行 |
| 水平零点 | **raw = 6493** | 球不滚 + 水平仪约 0° |
| 工作半宽 | **±14°** | T 命令夹紧范围 |
| 角度输出 RPM 限幅 | **±40** | 角度环输出封顶 |

---

## 6. A0 数据行字段（看曲线用）

典型一行（字段以固件为准）：

```text
tgt, act, volt, err, isum, en, rx, tx, mode, tdeg, traw, raw, aerr
```

| 字段 | 含义 |
|------|------|
| tgt | 速度环目标 RPM（角度模式下=角度环输出） |
| act | 实测 RPM |
| volt | 电压给定 |
| err / isum | 速度环误差 / 积分 |
| en | 1=使能 |
| rx / tx | CAN 收帧 / 控制发送计数 |
| mode | 0=速度 1=角度 |
| tdeg | T 目标倾角 ° |
| traw | 换算后的目标 raw |
| raw | 当前编码器 raw |
| aerr | 角度误差 tick（目标 raw − 当前） |

诊断行以 `#` 开头，绘图可当注释。

## 7. 推荐操作流程

### 7.1 上电自检

```text
A0
Q
```

确认 CAN `rx` 在涨、限位/零点打印正常。

### 7.2 角度环静置（水平）

```text
E1
T0
J0.12
L0.10
```

**期望（贴水平时）：**

- `raw` 钉在 **6493** 附近（±1 tick 可接受）
- `tgt` 接近 0
- `volt` 不再大幅正负扫

### 7.3 小步进

```text
T3
（等几秒）
T0
```

看能否跟上、有无来回晃。大误差时若持续振荡，优先分析结构/内环积分，不要只把 L 拧到 0。

### 7.4 只测速度内环

```text
V5
E1
```

或 `V20`（确认限位与方向后再加大）。

### 7.5 结束

```text
S
```

或 `E0`。

## 8. 实测调参记录（OmniProbe，T0 已接近水平时）

条件：`E1` + `T0`，`J=0.12`，只扫角度 **L**。

| L | 静置观感（摘要） | 备注 |
|---|------------------|------|
| 0.40 | 可贴住，volt 仍有小波动 | 代码默认 Kd |
| 0.20 | 更干净 | |
| **0.10** | **静置较优** | 推荐先用 |
| 0 | 更静，但阻尼更弱 | 大步进刹车差 |
| J0.08 + L0.10 | 也静 | 步进更肉 |

**说明：**

- 学长「可能是 D 大了」在 **已到位微抖** 场景成立 → 降 **L**。
- **从远处回 T0 / 大误差** 时 raw 大幅扫，单降 D 不能当唯一最优解；需另看速度环积分与外环大误差行为。

---

## 9. 现象 → 拧哪个旋钮

| 现象 | 优先动作 |
|------|----------|
| T0 到位后轻轻抖，`tgt`/`volt` 小幅晃 | 降 **L**（0.40→0.20→0.10） |
| L 已很小仍抖 | 略降 **J**；再考虑结构（死区/积分），不要死加 K |
| T3→T0 来回晃、isum 大幅甩 | 不只拧 L；查速度环 I、大误差限幅 |
| E1 后 volt/err 全 0 | 看 `rx`：无 CAN 反馈则环路安全锁 |
| 跟手太慢 | 略增 **J**，或确认不是 L=0 |
| 冲过目标 | 略增 **L**，或略减 **J** |
| 改完 Ki 电机猛窜 | 正常风险；改 **I/K** 会清对应积分 |

## 10. 命令速查（一张表）

```text
T0 / T±x     角度目标（度，相对水平）
V±x          速度目标（RPM），切速度模式
E1 / E0      使能 / 关
S            急停
A0 / A1      数据曲线 / 角度注释
Q            查询
J / K / L    角度环 Kp / Ki / Kd
P / I / D    速度环 Kp / Ki / Kd
F1 / F-1     转向符号
```

## 11. 当前推荐默认（联调）

```text
速度环：P55  I0.55  D0
角度环：J0.12  K0  L0.10
零点：  raw 6493
工作区：±14°
Flash： SAVE/W 保存 | LOAD/R 加载 | **开机自动 Load**
地址： Sector7 @ 0x08060000（magic 与 ytbeif 云台参数隔离）
版本： **v5**（位置环改为10ms/100Hz；v2/v3/v4 旧存档会自动迁移，敲一次 SAVE 升级）
内容： 速度 P/I/D、角度 J/K/L、水平零点 raw、工作半宽°、转向
       \+ 位置环 X/Y/Z、目标mm、倾角限幅、死区、变化率、方向符号
```

> 位置环（最外环，10ms/100Hz）已接上，命令 **B/X/Y/Z/G/H/U/M/N**，
> 见 `docs/位置环调参指令.md`。默认开启；敲 `T` 或 `V` 会自动关掉位置环。

调完并确认可接受后（与 ytbeif 相同口令）：

```text
SAVE
```

上电应看到：

```text
# FLASH load OK
#   spd P=... I=... D=...
```

无存档：

```text
# FLASH empty, use defaults ...
```

**说明：** 即使用 P55/I0.55/D0，大步进 T3→T0 仍可能来回晃——不完全是“忘了改速度环”，外环大误差/内环积分行为仍要继续治。Flash 只负责记住你调好的数。
